  • 🌟 경험치 계산기 — Lv 1 ~ Lv 290 까지 지원. 현재 Lv + 목표 Lv 드롭다운 선택 → 필요 경험치 즉시 계산
  • 🌰 스킬 레벨업 열매 계산기 — Lv 1 ~ Lv 30 까지 지원. 스킬 1개 풀레벨까지 104,200개 필요
  • 각 레벨별 비용을 합산해서 계산: Lv X → Y 비용 = arr[X] + arr[X+1] + ... + arr[Y−1] (각 단계별 비용의 합)

💰 자원 관련

📦 보유자원/가속 계산하기

인벤토리만 따로 관리하고 싶을 때 사용하는 별도 탭. 목표캠프계산기와 독립으로 동작합니다.

  • 골드/목재/강철 보유량, SR/SSR/UR 상자 수, 가속권 5종 (일반/건설/연구/훈련/의료) 입력
  • 맨 아래 요약: 상자 전부 개봉 시 자원 + 가속권 종류별 총합
  • 여기서 입력한 값은 목표캠프계산기의 [📥 불러오기] 버튼으로 가져갈 수 있음

📊 캠프별 자원상자 비교

같은 보유 상자를 어느 캠프 레벨에서 까는 게 이득인지 비교.

  • 내 캠프 레벨 과 비교 캠프 두 드롭다운 선택
  • 각 자원(팰몬 경험치/전력/골드/강철/목재)별 SR/SSR/UR 상자 보유 수 입력
  • 두 캠프 레벨에서 까면 각각 얼마인지 + 증가량/증가율 한눈에 비교

📦 상자시뮬레이터

🌰 열매상자

보유한 열매상자를 한 번에 깠을 때 어떤 결과가 나오는지 확률 기반 랜덤 시뮬레이션.

  • 보유 수량 입력 → ✅ 확인하기 버튼 → 결과창에 UR/SSR/SR 열매 이미지 + 갯수 표시
  • 메뉴 설명글의 📊 확률표 보기 버튼으로 9행 상세 확률표 토글
  • 드롭 확률 (상자 1개당):
    • 🟡 레전드 스킬 열매 — 5개 9.09% / 10개 18.18% / 15개 9.09% (합 36.36%)
    • 🟣 에픽 스킬 열매 — 5개 9.09% / 10개 27.27% / 15개 9.09% (합 45.45%)
    • 🔵 레어 스킬 열매 — 5개 4.55% / 10개 9.09% / 15개 4.55% (합 18.19%)
  • ⚠️ 항상 랜덤한 결과입니다. 너무 믿지 마세요.

🌐 기타 탭

🗺️ 자리배치도

게임 내 건물 자리배치를 시각적으로 설계하는 도구. 1300×1300 픽셀 맵을 13×13 셀로 나눠 표시하고, 셀 클릭 → 100×100 픽셀 상세 화면에서 정확한 위치에 건물을 배치합니다.

  • 7가지 건물 종류 — 🌾 자원지(1×1) / 📦 상자(1×1) / 👹 팰몬(엘리트)(1×1) / 🐾 팰몬무리(3×3) / ⚙️ 길드발전기(6×6) / 🏠 캠프(3×3) / 🏛️ 성전(9×9)
  • 🛡️ 신전 자동 고정 — 맵 정중앙(646,646)에 9×9 신전이 항상 표시. 이동/삭제 불가, 다른 건물도 그 위에 못 놓음
  • 🌊 지형 페인트 — 호수/얼음/장애물 등을 픽셀 단위로 칠하기 (드래그로 연속). 칠한 픽셀 위에는 건물 배치 불가
  • 이름 커스텀 — 배치된 건물 클릭 → 팝업에서 이름 변경 (예: "메인 캠프", "1차 성전") + ⚙️ 설정으로 위치 이동, 🗑️ 제거
  • 🔍 검색 + 네비게이션 — 배치된 건물 조회에서 이름/타입 검색 → 클릭 시 그 위치로 자동 이동. 신전도 검색 가능
  • 📄 PDF 저장 — 디테일 화면 상단 버튼 → 서버명 입력 → 2페이지 PDF 자동 생성 (1페이지: 상세지도 / 2페이지: 캠프·길드발전기 이동 요청 리스트)
  • 💾 자리배치 저장/불러오기 — 상단 버튼으로 JSON 파일 저장. 다른 사람에게 카톡/메일로 공유 가능. 받은 사람은 📂 불러오기로 동일한 배치 확인
  • 확대/축소/이동 — +/− 버튼, 마우스 휠, 모바일 핀치/드래그 지원. 페인트 모드에서는 드래그가 페인트로 동작

💾 설정 저장 / 불러오기

  • 설정 저장 — 모든 입력값이 JSON 으로 다운로드 + 브라우저에 자동 저장. 같은 브라우저에서는 다음 방문 시 자동 복원
  • 설정 불러오기 — 다운받아둔 JSON 파일을 선택하면 입력값 복원
  • 초기화 — 모든 입력 + 저장값 삭제

📱 모바일 / 핸드폰

화면 너비에 따라 자동으로 1~5열 레이아웃이 조정됩니다. 탭바도 좌우 스와이프 가능. iOS / Android 모두 지원.

💡 상단 로고

상단 Palmon Tool 로고를 누르면 언제든 이 사용법 페이지로 돌아옵니다.

📝 메뉴 설명글

서버 / 닉네임만 입력하면 누구나 글과 댓글을 남길 수 있는 익명 게시판입니다.
상단 카테고리 탭으로 게시판을 전환하거나 + 버튼으로 새 게시판을 만들 수 있고, 📌 버튼 / 우클릭으로 자주 보는 게시판을 상단에 고정할 수 있어요.
📌 먼저 원하는 게시판을 선택한 후, 글 작성 및 댓글 작성 부탁드립니다.
