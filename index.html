📖 사용법

🎯 목표캠프계산기

이 도구의 메인 탭입니다. 입력하면 자동으로 캠프 목표 달성에 필요한 시간/자원/가속권이 계산됩니다.

  1. 건물 레벨 / 목표 캠프 — 현재 5개 건물 레벨과 도달하고 싶은 목표 캠프 레벨을 선택
  2. 시간 버프 / 자원 감소 버프 — VIP·연구·길드·시즌·직위·관리자·결제·LV6 점령·작업파견 가속 등 모든 보너스 입력
  3. 보유 자원 / 자원 상자 / 가속권 (5종) — 직접 입력하거나, 위쪽 📥 보유자원/가속 데이터 불러오기 버튼으로 옆 탭 값을 한 번에 가져옴
  4. → 화면 맨 아래 🎯 자동 계산 결과 카드에 즉시 표시됨

📦 보유자원/가속 계산하기

인벤토리만 따로 관리하고 싶을 때 사용하는 별도 탭. 목표캠프계산기와 독립으로 동작합니다.

  • 골드/목재/강철 보유량, SR/SSR/UR 상자 수, 가속권 5종 (일반/건설/연구/훈련/의료) 입력
  • 맨 아래 요약: 상자 전부 개봉 시 자원 + 가속권 종류별 총합
  • 여기서 입력한 값은 목표캠프계산기의 [📥 불러오기] 버튼으로 가져갈 수 있음

💎 걸작 구슬

구슬로 무기를 만들 때 사용. 보유 구슬과 초기화할 무기를 입력하면 완성 가능 무기 수가 즉시 표시.

  • 무기 1개당 구슬 150 필요 (5성 기준)
  • 초기화 환급(누적): 1성 +10 / 2성 +30 / 3성 +60 / 4성 +100 / 5성 +150 / 6성 +225 / 7성 +325 / 8성 +525 / 9성 +825 / 10성 +1325
  • [원하는 성급] 드롭다운으로 5성이 아닌 다른 등급 완성 수도 확인 가능

✨ 팰몬 진화

승급 / 진화 정수를 활용해 팰몬을 키울 때.

  • UR 만능 팰몬조각 (승급) — 보유 수량 입력 → 975 ÷ 1명 → 승급 가능 인원 표시
  • 진화 정수 — 보유 수량 + 초기화할 팰몬(1~4진화 수량) 입력 → 진화 가능 인원 표시
  • 초기화 환급(누적): 1진화 +20 / 2진화 +60 / 3진화 +140 / 4진화 +300
  • [원하는 진화] 드롭다운으로 특정 단계 목표 인원 확인 가능
  • 풀세팅 완성 인원 = 승급 가능 ∩ 진화 가능

📊 캠프별 자원상자 비교

같은 보유 상자를 어느 캠프 레벨에서 까는 게 이득인지 비교.

  • 내 캠프 레벨 과 비교 캠프 두 드롭다운 선택
  • 각 자원(팰몬 경험치/전력/골드/강철/목재)별 SR/SSR/UR 상자 보유 수 입력
  • 두 캠프 레벨에서 까면 각각 얼마인지 + 증가량/증가율 한눈에 비교

💾 설정 저장 / 불러오기

  • 설정 저장 — 모든 입력값이 JSON 으로 다운로드 + 브라우저에 자동 저장. 같은 브라우저에서는 다음 방문 시 자동 복원
  • 설정 불러오기 — 다운받아둔 JSON 파일을 선택하면 입력값 복원
  • 초기화 — 모든 입력 + 저장값 삭제

📱 모바일 / 핸드폰

화면 너비에 따라 자동으로 1~5열 레이아웃이 조정됩니다. 탭바도 좌우 스와이프 가능. iOS / Android 모두 지원.
