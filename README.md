# Palmon Tool — 사용법

캠프 레벨업 계산기 + 자원/가속 관리 + 팰몬 진화 / 스킬 / 자원상자 비교 + 상자·소환 시뮬레이터 + 🃏 블랙잭 계산기 + 자리배치도 + 익명 게시판이 통합된 도구입니다.

탭 구조는 **대분류 → 서브탭** 2단계로 정리되어 있으며, 1차 탭(대분류) 클릭 시 녹색 밑줄로 서브탭이 나타나고 브레드크럼(경로)이 표시됩니다.

헤더에는 **📖 팰몬 가이드 배너**가 있어서 [Palmon Survival Wiki](https://palmon-survival-wiki.vercel.app/) 로 바로 이동할 수 있습니다.

## 🏗️ 건설 관련

### 🎯 목표캠프계산기 (메인)

목표 캠프 레벨에 도달하기 위한 시간/자원/가속권을 자동으로 계산합니다.

1. **건물 레벨 / 목표 캠프** — 현재 5개 건물 레벨과 도달하고 싶은 목표 캠프 레벨을 선택
2. **시간 버프 / 자원 감소 버프** — VIP·연구·길드·시즌·직위·관리자·결제·LV6 점령·작업파견 가속 등 모든 보너스 입력
3. **보유 자원 / 자원 상자 / 가속권 (5종)** — 직접 입력하거나, 상단 `📥 보유자원/가속 데이터 불러오기` 버튼으로 옆 탭 값을 한 번에 가져옴
4. → 화면 맨 아래 **🎯 자동 계산 결과** 카드에 즉시 표시 (계산 버튼 없음)

## 💎 팰몬 관련

### 💎 걸작 구슬

구슬로 무기를 만들 때 사용. 보유 구슬과 초기화할 무기를 입력하면 완성 가능 무기 수가 즉시 표시됩니다.

- **무기 1개당**: 구슬 150 (5성 기준)
- **초기화 환급 (누적)**:
  - 1성 +10 / 2성 +30 / 3성 +60 / 4성 +100 / 5성 +150
  - 6성 +225 / 7성 +325 / 8성 +525 / 9성 +825 / 10성 +1325
- `원하는 성급` 드롭다운으로 5성이 아닌 다른 등급 완성 수도 확인 가능

### ✨ 팰몬 진화

승급 / 진화 정수 / 메가 진화석 / 에너지 구슬을 활용해 팰몬을 키울 때 사용.

- **UR 만능 팰몬조각 (승급)**: 보유 수량 입력 → 975 ÷ 1명 → 승급 가능 인원 표시
- **진화 정수 + 메가 진화석**: 한 카드에 두 자원 나란히. 일반 진화(1~4단계)는 진화 정수, 메가진화(5~8단계)는 메가 진화석 사용
- **초기화 환급 (누적)**:
  - 일반: 진화 1단계 +20 / 2단계 +60 / 3단계 +140 / 4단계 +300
  - 메가: 진화 **5단계 +1** / 6단계 +40 / 7단계 +80 / 8단계 +160
- `원하는 진화` 드롭다운으로 **총 8단계** 중 목표 선택 → 해당 단계 기준으로 완성 인원 표시
- 초기화할 팰몬은 통합 섹션 (1~8단계 한 곳에 입력)
- **풀세팅 완성 인원** = 승급 가능 ∩ 진화 가능 (일반 4단계 기준)

#### 🔮 에너지 구슬 (진화 조건)

팰몬을 다음 진화 단계로 넘기기 위한 **진화 조건** 충족용 재료 (진화 정수와는 별도). 같은 탭 안에 통합되어 있음.

- **현재 단계** ("처음 시작" 가능) + **목표 단계** 드롭다운 → 필요 에너지 구슬 자동 계산
- **보유량 입력** → 부족/충분 + 단계별 분해 표시
- 각 소단계당 **10번 강화** 필요 (소단계 1회 = 표시값 ÷ 10)
- **단계별 합계**:
  - 진화 1단계: 30,000 / 2단계: 60,000 / 3단계: 90,000 / 4단계: 220,000 → 진화 합계 **400,000**
  - 메가 5단계: 30,000 / 6단계: 60,000 / 7단계: 90,000 / 8단계: 162,000 / 스킬해금: 58,000 → 메가 합계 **400,000**
- **전체 합계 (진화 1-1 → 메가 스킬해금)**: **800,000개**

### 🌰 스킬열매 / 경험치

현재 레벨에서 목표 레벨까지 올리는 데 필요한 경험치 / 스킬 열매 갯수를 자동 계산.

- **🌟 경험치 계산기** — Lv 1 ~ Lv 300 지원. 현재 Lv + 목표 Lv 드롭다운 선택 → 필요 경험치 즉시 계산
- **🌰 스킬 레벨업 열매 계산기** — Lv 1 ~ Lv 30 지원. 스킬 1개 풀레벨까지 **104,200개** 필요
- 💡 **자원 관련 → 📦 보유자원/가속 계산하기** 에서 경험치 상자(SR/SSR/UR) 보유 수량을 입력해두면, 이 탭의 필요 경험치 카드 밑에 **"보유 상자로 몇 개 까면 충분한지"** 자동 추천 표시
- 각 레벨별 비용을 합산해서 계산

## 💰 자원 관련

### 📦 보유자원/가속 계산하기

인벤토리만 따로 관리하는 별도 탭. 목표캠프계산기와 독립적으로 동작합니다.

- 💰 골드 / 🪵 목재 / 🧱 강철 / **⚔️ 전력** / 🥚 경험치 보유량 입력
- 자원 상자 SR/SSR/UR 개수 입력 (각 자원별)
  - ⚔️ **전력 상자**: SR 44,000 / SSR 356,000 / UR 1,500,000 (고정 값)
  - 🥚 경험치 상자: 캠프 레벨에 따른 DB 값 사용
  - 📦 커스텀 상자: 골드/목재/강철 중 원하는 자원에 자동 분배
- 가속권 5종 (일반 / 건설 / 연구 / 훈련 / 의료) 5분/1분/8시간/3시간/1시간 각각 입력
- 맨 아래 요약: **상자 전부 개봉 시 자원** 총합 + 가속권 종류별 총합
- 여기서 입력한 값은 목표캠프계산기의 `📥 불러오기` 버튼으로 가져갈 수 있음

### 📊 캠프별 자원상자 비교

같은 보유 상자를 어느 캠프 레벨에서 까는 게 이득인지 비교.

- `내 캠프 레벨`과 `비교 캠프` 두 드롭다운 선택
- 각 자원(팰몬 경험치 / 전력 / 골드 / 강철 / 목재)별 SR/SSR/UR 상자 보유 수 입력
- 두 캠프 레벨에서 까면 각각 얼마인지 + 증가량/증가율 한눈에 비교

## 📦 시뮬레이터

상자를 한 번에 깠을 때 또는 소환을 돌렸을 때의 결과를 확률 기반으로 시뮬레이션합니다. 서브탭 공통 — 메뉴 설명글의 **📊 확률표 보기** 버튼으로 전체 확률표 토글, **⚠️ 항상 랜덤한 결과입니다. 너무 믿지 마세요** 주의 문구 포함.

### 🌟 오로라 소환

오로라 구슬로 신화 팰몬을 뽑을 때까지 자동 시뮬레이션.

- **🔮 신화 팰몬 미보유 모드**: 친밀도 시스템 활성 (1200 도달 시 자동 획득, 0.13% 직접 획득)
- **✨ 신화 팰몬 보유 모드**: 친밀도 없음, 아이템만 100% 분배
- 10종 아이템 확률표 (커스텀상자, 전력 보물상자, 팰몬조각, 스킬 열매, 보물상자 4종 등)
- 보유 모드 전용: **🎯 오로라 정수 → 필요 구슬 계산기**
- 예상 필요 구슬 (친밀도 1200까지) 실시간 계산

### 🌌 메가 팰몬 뽑기

메가 팰몬 뽑기 (친밀도 800 도달 자동 획득 시스템). 오로라 구슬 공용 사용. 상세 확률표 준비 중.

### 🌰 열매상자

보유한 열매상자를 한 번에 깠을 때 결과를 확률 기반 랜덤 시뮬레이션.

- **보유 수량 입력** → ✅ **확인하기** 버튼 → 결과창에 UR/SSR/SR 열매 이미지 + 갯수 표시
- **드롭률 (상자 1개당)**:
  - 🟡 레전드 — 5개 9.09% / 10개 18.18% / 15개 9.09% (합 36.36%)
  - 🟣 에픽 — 5개 9.09% / 10개 27.27% / 15개 9.09% (합 45.45%)
  - 🔵 레어 — 5개 4.55% / 10개 9.09% / 15개 4.55% (합 18.19%)

### 🪖 개선장군 보급

개선장군 보급 상자(20종 아이템) 결과를 확률 기반 랜덤 시뮬레이션.

- **주요 드랍률**:
  - 🪵 목판 / ⚙️ 강철 / 🪙 골드 레벨 보물상자 — 각 **23.19%**
  - 💎 다이아 10개 — **10%**
  - 🎖️ 개선 훈장 10개 — **5%**
  - 💠 강화 결정(소) 200개 — **5%**
  - 💎 다이아 50개 — **2.5%**
  - 🥚 팰몬 알 1개 / 🟡 UR 만능 증표 / ⚡ 가속권 5종 각각 — **1~1.5%**
  - 희귀: 💎 다이아 10,000개 (0.01%) / 🗿 화려한 조각상 (0.05%) 등

### 🎁 미스테리박스

미스테리박스(17종 아이템) 결과를 확률 기반 랜덤 시뮬레이션.

- **주요 드랍률**:
  - 🪵 10K 목판 / ⚙️ 10K 강철 / 🪙 10K 골드 보물상자 — 각 **28.98%**
  - 💠 강화 결정(소) 100개 — **2.5%**
  - 🧭 보물찾기 나침반 / ✈️ 비행선 갱신권 — 각 **2%**
  - 💎 다이아 10개 / ⚡ 가속권 5종 각각 — **1%**
  - 🥚 팰몬 알 0.25% / 🗿 화려한 조각상 0.1% / 🟡 UR 만능 증표 0.1% / 💎 다이아 5000개 0.01%

### 🦅 이글아이 보물상자

이글아이 보물상자(7종 아이템) 결과를 확률 기반 랜덤 시뮬레이션.

- **드랍률**:
  - 💠 강화 결정(소) 100개 — **41.9%**
  - 🎯 10 AP — **41.9%**
  - 💧🔥🪨⚡ 물/불/바위/전기 조각상 정수 — 각 **3.35%**
  - 🟡 UR 팰몬 만능 증표 — **2.79%**

### 🃏 블랙잭

블랙잭 미니게임 **매판 전략 도우미 (실시간 뽑기 판단)**. 골드카드로 카드를 뽑아 점수 배수에 따라 코인을 획득하는 게임의 최적 결정을 도와줍니다.

- **게임 규칙**: 라운드당 카드 3~5장 (3장 이상이어야 결산 가능, 한 판 내 중복 카드 없음)
- **점수**: A=11, 2~10=숫자값, J/Q/K=10
- **비용 (2가지 모드)**:
  - 🎯 **일반 모드**: 카드 1장 뽑을 때마다 골드카드 **1개** 소모 (배율 ×1)
  - 💎 **10배 모드**: 카드 1장 뽑을 때마다 골드카드 **10개** 소모 (배율 ×10)
- **점수 배수표**:
  - 0~20점: ×1 → 200코인 (10배: 2,000)
  - 21~35점: ×2 → 400코인 (10배: 4,000)
  - 36~45점: ×3 → 600코인 (10배: 6,000)
  - 46~54점: ×5 → 1,000코인 (10배: 10,000)
- **매판 전략 도우미**:
  - 13개 카드 버튼(2~A)으로 지금까지 뽑은 카드 입력
  - **백워드 인덕션 알고리즘**으로 최적 결정 계산
  - "지금 결산" vs "한 장 더 뽑기" 골드카드 1개당 가치 비교
  - **🎴 계속 뽑기** / **🛑 결산 (멈추기)** 명확한 추천
  - **결과 분포 시각화**: 각 코인 값별 확률 막대 표시
- **이론값 (최적 플레이)**: 골드카드 1개당 평균 ≈ **119.85 코인**

## 🌐 기타 탭 (대분류 없음)

### 🗺️ 자리배치도

게임 내 건물 자리배치를 시각적으로 설계하는 도구. 13×13 셀 → 100×100 픽셀 줌인으로 정확한 위치에 건물 배치.

- **7가지 건물**: 🌾 자원지 / 📦 상자 / 👹 팰몬(엘리트) / 🐾 팰몬무리(3×3) / ⚙️ 길드발전기(6×6) / 🏠 캠프(3×3) / 🏛️ 성전(9×9)
- **🛡️ 신전** 맵 중앙(646,646)에 9×9 자동 고정 — 이동/삭제 불가
- **🌊 지형 페인트** 호수/얼음/장애물을 픽셀 단위로 칠하기. 드래그 연속 페인트. 칠한 곳엔 건물 배치 불가
- **이름 커스텀** 배치된 건물 클릭 → 팝업에서 이름 변경, ⚙️ 위치 이동, 🗑️ 제거
- **🔍 검색** 이름/타입으로 빠르게 찾기 → 클릭 시 자동 이동 (메인/디테일 양쪽)
- **📄 PDF 저장** 2페이지 PDF 자동 생성 (1: 상세지도 / 2: 캠프·길드발전기 이동 요청 리스트)
- **💾 JSON 저장/불러오기** 자리배치 데이터를 파일로 저장 → 길드원과 공유
- **정보 패널 sticky** 스크롤해도 우측 정보 패널이 따라옴 + 접기/펼치기 가능

### 📋 게시판 (익명 게시판)

다중 카테고리 익명 게시판. 다른 사용자와 정보 공유.

- 카테고리(자유/공략/거래 등) 탭으로 전환
- `+` 버튼으로 새 카테고리 만들기
- `✏️ 글쓰기` → 서버/닉네임/제목/내용/이미지 입력 후 작성
- 게시글 클릭 → 상세 보기 + 💬 댓글
- 본인이 쓴 글/댓글만 🗑️ 삭제 가능 (같은 브라우저 기준)
- 서버/닉네임은 한 번 입력하면 자동 채워짐 (게시글 + 댓글 양쪽 모두)

### 📰 업데이트 현황

Palmon Tool 의 업데이트 내역을 확인할 수 있는 페이지. 최신 업데이트가 맨 위에 표시되며 ✨ 신규 / 🔧 개선 / 🐛 버그수정 3종 태그로 구분.

### 📖 사용법

지금 보고 있는 페이지. 상단 **Palmon Tool** 로고를 누르면 언제든 돌아올 수 있음.

## 🎪 모험가대회 배너

## 💾 설정 저장 / 불러오기

- **설정 저장** — 모든 입력값을 JSON 파일로 다운로드 + 브라우저에 자동 저장. 같은 브라우저에서는 다음 방문 시 자동 복원.
  - 파일명: `PAL_닉네임_YYYY-MM-DD.json`
  - 첫 저장 시 닉네임 입력 (이후 자동 기억)
  - 저장 항목: 자원(⚔️ 전력 포함), 상자, 가속권, 진화·구슬·경험치 입력값 등 전체
- **설정 불러오기** — 다운받아둔 JSON 파일을 선택하면 입력값 복원
- **초기화** — 모든 입력 + 저장값 삭제
