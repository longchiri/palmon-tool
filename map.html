🗺️ 팰몬 자리배치도 1300 × 1300 px · 13 × 13 셀
📝 메뉴 설명글
Palmon Map은 게임 내 건물 자리배치를 시각적으로 설계할 수 있는 도구입니다.
🗺️ 메인 지도는 1300×1300 픽셀의 전체 맵을 13×13 셀로 나눠 보여줍니다.
📍 셀을 클릭하면 100×100 픽셀의 상세 지도로 들어가서 건물을 정확한 픽셀 위치에 배치할 수 있어요.
🔍 검색창에 이름이나 종류를 입력하면 배치된 건물을 빠르게 찾을 수 있고, 클릭하면 그 위치로 자동 이동합니다.
100%
①
건물 종류 선택
아래 알약 버튼(🌾 자원지 / 📦 상자 / 👹 팰몬엘리트 / 🐾 팰몬무리 / ⚙️ 길드발전기 / 🏠 캠프 / 🏛️ 성전) 중 하나를 클릭하면 배치 모드 활성
②
픽셀 클릭으로 배치
100×100 그리드 안에 원하는 픽셀을 클릭하면 그 자리에 건물이 들어감. 다른 건물/신전/지형과 겹치는 위치는 빨간색으로 표시되고 배치 불가
③
배치된 건물 클릭 → 설정/제거/이름 변경
배치된 건물 클릭 시 팝업이 떠서 이름 입력 + ⚙️ 설정(위치 이동) + 🗑️ 제거 가능
④
🌊 지형 페인트로 호수/장애물 표시
호수, 얼음, 숲 등 게임 내 장애물을 픽셀 단위로 칠해두면 그 위에는 건물이 배치되지 않음. 드래그로 연속 페인트 가능. 지우개로 제거
⑤
📄 PDF 저장
상단 "PDF 저장" 버튼 → 서버명 입력 → 2페이지 PDF 자동 생성. 1페이지=상세지도, 2페이지=캠프/길드발전기 이동 요청 리스트
⑥
🛡️ 신전은 고정
맵 중앙(646,646)에 9×9 신전이 항상 고정. 이동/삭제 불가. 다른 건물은 신전 위에 못 놓음
⑦
확대/축소/이동
+/- 버튼이나 마우스 휠로 줌. 드래그로 이동. 모바일에서는 핀치 줌 + 한 손가락 드래그. 페인트 모드에선 페인트만 동작
